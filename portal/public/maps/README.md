# Ethiopia map boundaries

`ethiopia-adm1.geojson` is a simplified Ethiopia first-level administrative-boundaries reference layer from [geoBoundaries](https://www.geoboundaries.org/).

- Source: geoBoundaries gbOpen, Ethiopia ADM1
- License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- Download metadata: https://www.geoboundaries.org/api/current/gbOpen/ETH/ADM1/

The portal uses this file only as a visual geographic reference. The Customs Valuation database remains the authority for the current Region → Branch hierarchy.
